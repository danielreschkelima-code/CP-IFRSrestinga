# Mini Guia de Lógia de Programação
Essa pasta é praticamente um mini curso de lógica de programação em Python e JavaScript, ao mesmo tempo. Ao final dele, tu vai aprender não só por completo a lógica de programação, como também o básico de Python e Javascript, além de já conseguir fazer coisinhas bem legais e úteis no terminal! Parece loucura aprender as duas linguagens ao mesmo tempo, mas não é: as duas utilizam a mesma lógica, pensamento computacional, e nós vamos treinar isso. E, caso tu realmente não queira, será possível também trabalhar só com uma.

## Como vai funcionar?
O guia é dividido em 6 unidades com explicações profundas e práticas, e no final de cada unidade há exercícios para prática e fixação dos contéudos. Vai ter uma seção com a demonstração dos comandos em Python e uma em JavaScript, tu pode escolher em qual linguagem programar ou até mesmo programar com as duas ao mesmo tempo. Independete disso, tu pode ou
- Caso tu seja iniciante e não saiba de nada: Fazer ele todo em ordem, seguindo cada conteúdo conforme a numeração e fazendo os exercícios certinhos para entender bem
ou...
- Caso só reforçar alguma coisa que não esteja bem clara: Ir direto pra unidade correspondente e ler o conteúdo ou só pegar os exercícios mesmo.

## Do que eu preciso?
Paciência pra aprender, qualquer editor de texto/código e instalar o interpretador de Python e o de JavaScript no teu computador.
Obs: Interpretador é uma ferramenta que o teu computador vai usar pra entender teu código.
